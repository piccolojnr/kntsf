## Abstract

Manual and fragmented student governance workflows create delays, weak auditability, and unreliable permit verification at Knutsford University. This study designed and implemented an NFC-based student permit verification and governance management system that centralizes permit management, payment verification, NFC-assisted identity checks, election voting, public communication, audit logging, reporting, and mobile access within one coordinated platform. The system uses a Laravel backend with an operations dashboard built using React and Inertia.js, a public portal, an Expo React Native mobile application, a Sanctum-protected mobile API, PostgreSQL data storage, Paystack payment verification, queue and cache support, and role-based access control. The design connects self-service permit requests to server-side payment confirmation, supports NFC card registration and verification with student number and permit code fallbacks, and applies stricter controls to student election voting than informal polls. Implementation and testing covered authentication, authorization, permit workflows, payment recovery, NFC lifecycle management, verification logging, elections, public content visibility, mobile API access, and security restrictions. The study concludes that the platform provides a practical foundation for improving SRC operations, but successful institutional use still depends on deployment readiness, user training, policy alignment, and future enhancements such as offline verification support and expanded analytics.
