## Abstract

Manual student governance processes at Knutsford University create delays, weak auditability, and unreliable permit verification. This project designed and implemented an NFC-based student permit verification and governance management system that centralizes permit management, Paystack payment verification, NFC-assisted identity checks, election voting, public communication, audit logging, and mobile access. The solution uses a Laravel backend, a React and Inertia.js operations dashboard, a public portal, an Expo React Native mobile application, a Sanctum-protected mobile API, PostgreSQL, queues, and role-based access control. Self-service permit requests are linked to server-side payment confirmation. Verification supports NFC cards with student number and permit code fallbacks. Election voting applies eligibility checks and duplicate-vote prevention. Testing covered authentication, permits, payments, NFC lifecycle, elections, mobile API access, and authorization. The system provides a practical foundation for improving SRC operations subject to deployment readiness, user training, and policy alignment.
